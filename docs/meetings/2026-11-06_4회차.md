## 회의 내용

### 인원 변동에 따른 역할 재분배

- 김민찬 팀원이 팀에서 빠지게 되어 3인에서 2인 체제로 변경
- 김민찬이 맡았던 PaddleOCR 글자 추출 파트를 정희재가 이어받고, 남은 작업을 두 명이 나누어 다시 분담
- 정희형 : OpenCV + 프론트엔드 + 도커
- 정희재 : PaddleOCR + 제미나이api 연결 + 다운로드
- 2인 체제에서도 서로의 코드를 검토할 수 있도록, 한 명이 PR을 올리면 다른 한 명이 리뷰·승인하는 방식으로 진행하기로 함

### GitHub 협업 및 버전 관리 방식 논의

- 앞으로 코드 수정 및 기능 추가 시 PR를 활용하여 코드 검토 후 병합하기로 결정
- 개발 과정에서 커밋을 자주 수행하고 커밋 메시지를 명확하게 작성하여 팀원 간 협업 효율성과 코드 관리의 편의성을 높이기로 함
