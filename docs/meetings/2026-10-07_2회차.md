## 회의 내용

### 주제 선정

->강의 형장 자료 자동 디지털화 및 정리 시스템

### 기능 구체화

- OpenCV로 원근/밝기/대비 등 보정
- PaddleOCR로 글자 추출
- 추출 텍스트 제미나이 API로 전송
- 제미나이가 핵심요약
- PDF생성, 웹에서 결과 확인 가능

### 역할 분담

- 정희형 : OpenCV 이미지 전처리 구현
- 김민찬 : PaddleOCR 이미지 추출
- 정희재 : 제미나이 api 연결
